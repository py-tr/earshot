Discovery: /sweep

Bob tabbed through /flights by ear (25 Tabs from the top, real NVDA), then five explore subagents checked suspects in parallel and produced 10 proposals across two runs. A third run on the Home page (/) produced 4 more, with four subagents in parallel.

Of those 10, the human accepted 3 (→ F-04, F-05, F-06), rejected 6, and marked 1 duplicate: S-02/S-03 (run 1) — same name, same target, allowed by WCAG 2.4.4; S-04 (run 1) — link inside h3 is valid, NVDA's announcement is standard; S-01 (run 2) — NVDA's "clickable" prefix comes from an ancestor click handler, not a WCAG failure; S-03/S-04 (run 2) — same reasons as run 1; S-05 (run 2) — duplicate of F-04.

On the Home page the human accepted all 4 as two findings: three buttons nested inside links, each heard twice in a row (one root cause, → F-07), and an icon-only GitHub link read as its web address (→ F-08; axe-core flags this one too).

Gate

Every UI commit runs all 6 screen-reader hear-tests as a git pre-commit hook (.githooks/pre-commit → earshot_mcp/hear_tests.py); if any test fails the commit is blocked and nothing reaches HEAD.

When Bob tried to "tidy up" the focus-management code in Modal.tsx (removing tabIndex={-1}, returnFocusRef, and the setTimeout focus call), the gate caught it immediately:

PS> git -C earshot commit -m "refactor: simplify Modal"
FAIL F-01: missing 'Sign In, dialog'
  said: Moon, link, heading, level 3
FAIL F-02: missing 'Register, button'
  said: Moon, link, heading, level 3
  said: Select Seat Class, Earth to Moon, button
  ...
FAIL F-03: missing 'Close modal, button'
  said: Moon, link, heading, level 3
  ...
PASS F-04
PASS F-05
PASS F-06
BLOCKED by Earshot: this change breaks what a screen reader hears.

Verbatim terminal output (trimmed where marked with ...); the full transcripts are in evidence/gate/. Without the focus handling, focus never entered the dialog, so all three dialog tests heard the page behind it.

Checking the first 6 announcements by hand with NVDA took a person 60 seconds at full speed, on every commit. The gate needs no attention: all 9 tests run unattended in about 6½ minutes.
